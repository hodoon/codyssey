# Javis 음성 녹음기 설명서 (javis.py)

이 문서는 화성 탐사 임무 중 음성 기록을 쉽게 남기기 위해 제작된 파이썬 스크립트 `javis.py`에 대한 설명입니다. 

## 1. 개요 및 요구사항 반영
본 스크립트는 매일 매일 화성에서의 생활을 음성으로 기록하고자 하는 한송희 박사의 요구에 따라 제작되었습니다. 
- 시스템의 마이크를 인식하고, 5초간 음성을 녹음합니다.
- 외부 라이브러리인 **PyAudio**를 사용하여 음성 데이터를 받아옵니다.
- 녹음된 파일은 앱이 실행되는 위치 하위의 `records` 폴더에 생성됩니다.
- 파일의 이름은 녹음된 시점을 기준으로 `YYYYMMDD-HHMMSS.wav`의 형태로 저장됩니다.
- PEP 8 스타일 가이드를 준수하여 띄어쓰기, 클래스/함수/변수 명명 규칙 등을 적용하였습니다.

## 2. 코드 구조 설명

### 2.1. `AudioRecorder` 클래스
이 클래스는 마이크를 통해 오디오 데이터를 수집하고 이를 `.wav` 파일로 저장하는 전체적인 책임을 담당합니다. (PEP 8에 따라 CapWords 형식 사용)

- `__init__(self, chunk_size, channels, rate)`:
  - `chunk_size` (기본 1024): 한 번에 메모리에 읽어들일 데이터의 청크 단위.
  - `channels` (기본 1): 모노 채널을 의미합니다.
  - `rate` (기본 44100): 오디오의 샘플링 레이트(Hz) 설정입니다.
- `record_audio(self, duration)`:
  - `duration` 시간(초) 동안 실제 오디오 스트림을 열어서 데이터를 반복적으로 읽어 들인 후 `frames` 리스트에 저장합니다.
- `_save_to_file(self, audio_interface, frames)`:
  - 내부적으로만 쓰이도록 설계된 메서드입니다(앞에 밑줄 `_` 추가).
  - `records` 폴더 존재 여부를 체크 및 생성하고, `wave` 모듈을 사용해 `frames` 리스트 안에 담긴 데이터를 설정된 파일명으로 저장합니다.

### 2.2. `find_records_in_range(start_date_str, end_date_str)` 함수
(보너스 과제 구현) 특정 기간 내에 저장된 녹음 파일을 찾아 출력해주는 함수입니다. (PEP 8에 따라 snake_case 형식 사용)

- 파라미터로 'YYYYMMDD' 형식의 문자열 두 개를 입력받습니다.
- `records` 폴더 내의 `.wav` 확장자를 가진 파일들을 찾습니다.
- 파일명(예: `20260410-170322.wav`)에서 날짜 부분(`20260410`)을 분리하여 입력된 검색 범위에 포함되는지 비교합니다.
- 범위 내에 해당하는 파일명들의 목록을 모아 콘솔에 출력합니다.

### 2.3. `main()` 함수
스크립트 실행 시의 진입점 역할을 합니다.
1. `AudioRecorder` 객체를 생성하여 5초 동안 녹음을 진행합니다.
2. 이후 녹음이 정상적으로 저장되었는지 확인하기 위해, 보너스 과제로 구현된 `find_records_in_range`를 호출하여 **오늘 생성된 녹음 파일의 목록**을 확인합니다.

## 3. 실행 방법
스크립트는 외부 라이브러리(PyAudio)에 의존하고 있으므로 환경에 설치되어 있어야 합니다. (macOS의 경우 `portaudio` 패키지가 먼저 설치되어야 할 수 있습니다)

```bash
# PyAudio 설치
pip install pyaudio

# 스크립트 실행
python javis.py
```

실행 시 `Recording...` 메시지와 함께 5초간 마이크로 입력된 소리가 녹음되고, `Finished recording.` 메시지와 함께 `records` 디렉토리에 파일이 저장됩니다. 이후 오늘 날짜에 생성된 녹음 파일들의 리스트가 출력됩니다.
