# door_hacking.py 설명

## 개요

`door_hacking.py`는 `emergency_storage_key.zip`의 비밀번호를 찾고, 성공하면 비밀번호와 압축 해제 결과를 `week10` 폴더에 저장하는 스크립트입니다.

## 동작 방식

1. ZIP 파일이 존재하는지 확인합니다.
2. ZIP 내부에서 가장 작은 일반 파일 하나를 선택합니다.
3. 의미 있는 키워드를 우선으로 비밀번호를 시도합니다.
4. 우선 탐색에 실패하면 멀티프로세싱으로 전체 조합을 병렬 탐색합니다.
5. 비밀번호를 찾으면 `key.txt`에 저장합니다.
6. 같은 비밀번호로 ZIP 파일을 `week10` 폴더에 압축 해제합니다.

## 우선 탐색 키워드

현재 먼저 시도하는 키워드는 아래와 같습니다.

- `mars`
- `door`
- `safe`
- `lock`
- `key`
- `pass`
- `code`
- `hint`
- `open`
- `star`

이 키워드들은 다음과 같은 형태로 조합됩니다.

- 단어 자체가 6자리인 경우 그대로 시도
- 단어 뒤에 숫자를 붙인 형태
- 단어 앞에 숫자를 붙인 형태
- 길이 차이가 1일 때 앞뒤에 알파벳 1개를 붙인 형태

예시:

- `mars12`
- `12mars`
- `code99`
- `amars`

## 전체 탐색 방식

우선 탐색에서 못 찾으면, 첫 글자 기준으로 작업을 나눠 여러 CPU 코어에서 병렬로 탐색합니다.

- 사용 문자: 소문자 `a-z` + 숫자 `0-9`
- 비밀번호 길이: 6자리

## 검증 방식

비밀번호 검증은 ZIP 내부의 가장 작은 파일을 실제로 끝까지 읽어서 확인합니다.

이 방식은 단순히 1바이트만 읽는 방식보다 느릴 수 있지만, 잘못된 비밀번호를 성공으로 오판할 가능성을 줄여줍니다.

## 생성되는 파일

성공 시 아래 결과가 저장됩니다.

- `key.txt`: 찾은 비밀번호
- 압축 해제된 파일들: `week10` 폴더 안에 저장

## 실행 방법

`week10` 폴더에서 아래 명령으로 실행합니다.

```bash
python3 door_hacking.py
```

## 참고

- ZIP 내부 경로가 `week10` 바깥으로 빠져나가지 않도록 간단한 안전 검사를 포함하고 있습니다.
- 키워드를 더 추가하고 싶다면 `PRIORITY_WORDS`를 수정하면 됩니다.
